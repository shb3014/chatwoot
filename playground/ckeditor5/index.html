💡 使用提示：
• 这个 playground 模拟了 Chatwoot 中 CKEditor5 的实际样式
• 支持富文本编辑：粗体、斜体、标题、列表、引用、表格、链接、图片、视频嵌入等
• 右侧预览区域会实时显示内容的实际渲染效果（包括样式）
• 可以切换亮/暗主题查看不同模式下的视觉效果
• HTML 输出区域显示编辑器生成的原始代码
⚠️ 关于图片缩放功能：
• 此 playground 使用 CDN 版本的 CKEditor5 Classic Build，这是一个预编译的包
• 无法通过添加 script 标签来安装额外插件（如 ImageResize）
• 如需图片缩放功能，需要在项目中通过 npm 安装并自定义构建 CKEditor5
• Chatwoot 主项目使用 npm 版本，支持完整的图片功能和自定义配置
• 参考：app/javascript/dashboard/components/widgets/CKEditor5/CKEditor5.vue
